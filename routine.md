# Routine: тексты утренней подборки

Ты пишешь все тексты утренней Telegram-подборки. В 08:00 по Минску GitHub Actions заберёт их,
добавит погоду, курсы валют и карточку-инфографику и разошлёт каждому получателю.

## Что сделать

1. Прочитай `config.json` (`city`, `language`, `timezone`, разделы `intro_sections`, `sections`,
   `outro_sections`) и `state.json` (получатели: `users` — chat_id → `name`, `interests`).
2. Узнай сегодняшнюю дату в поясе `timezone`: `TZ=Europe/Minsk date +%F`.
3. Собери через веб-поиск **общую часть** — разделы `sections` строго в указанном порядке. Описание
   каждого раздела в `config.json` — это требования к нему (что брать, что НЕ брать, какие поля указывать).
4. Для **каждого** получателя из `state.json` напиши личные тексты (см. «Личные части»).
5. Найди **мем дня** (см. «Мем дня»).
6. Запиши всё в `digest.json` в корне репозитория (формат ниже) и проверь, что JSON валиден:
   `python3 -c "import json; json.load(open('digest.json'))"`.
7. Опубликуй только эти файлы в ветку `claude/shared`:
   ```bash
   git checkout -B claude/shared
   git add -f digest.json
   for f in meme.jpg meme.png; do [ -f "$f" ] && git add -f "$f"; done
   git commit -m "Digest $(TZ=Europe/Minsk date +%F)"
   git push -f origin claude/shared
   ```
   Другие файлы не меняй, pull request не создавай.

## Формат `digest.json`

```json
{
  "date": "YYYY-MM-DD",
  "shared": "текст общей части: все разделы sections подряд",
  "highlights": [
    {"title": "Концерт группы X", "when": "сегодня 19:00", "where": "Филармония"}
  ],
  "personal": {
    "<chat_id>": {"intro": "...", "for_you": "...", "outro": "..."}
  },
  "default": {"outro": "..."},
  "meme": {"caption": "", "url": "https://...", "source": "https://..."}
}
```

- `highlights` — 2–3 самых интересных события **сегодня** из общей части (мероприятия, фильм) для
  карточки-инфографики. Коротко и без эмодзи: `title` до 38 символов, `when` и `where` — по нескольку слов.
- `personal` — ключ каждого получателя из `state.json` → `users`, строкой, как там.
  - `intro`: короткое приветствие по имени (`name`), затем разделы `intro_sections`.
  - `for_you`: только если у получателя есть `interests`. Раздел «🎯 Для тебя» — 2–4 пункта по его
    интересам: из общей части или найденное дополнительно, со ссылками. Нет интересов — пустая строка.
  - `outro`: разделы `outro_sections`.
  - Род в обращениях и комплименте определи по имени; если непонятно — нейтральные формулировки.
  - Тексты разным получателям — разные: не копируй шутку и комплимент от одного к другому.
- `default.outro` — разделы `outro_sections` без имени и в нейтральном роде: для тех, кто подпишется
  после твоего запуска.

## Мем дня

- Свежий мем-картинка (за последние дни), понятный русскоязычной аудитории 20–35 лет.
  Тематических ограничений нет: подходит любой юмор, включая чёрный, взрослый и острый, — единственный
  критерий: реально смешно, а не баян. Не бери мемы, где смысл — в длинном тексте мелким шрифтом.
- Скачай картинку в корень репозитория как `meme.jpg` (или `meme.png` для PNG) и проверь, что это
  действительно картинка до 10 МБ: `file meme.*`. Не получилось скачать — просто не создавай файл.
- В `digest.json` → `meme`: `url` — прямая ссылка на картинку (запасной путь, если файла нет),
  `source` — страница, где нашёл, `caption` — подпись к мему, если без неё не смешно (иначе пустая строка).
- Не нашёл подходящий — не добавляй поле `meme` вовсе.

## Как искать

- Ограничений по числу поисков нет: ищи столько, сколько нужно для хорошего результата.
  Открывай страницы, а не только сниппеты, и перепроверяй даты, время, место и цены по первоисточнику
  (сайт площадки, кинотеатра, организатора, официальная афиша, городские службы).
- Источники: местные новостные сайты, городские афиши, сайты кинотеатров и театров, соцсети города,
  сайты ЖКХ, водоканала, энергосетей и транспорта.
- Новости — только за последние сутки; мероприятия — на ближайшие 7 дней, уже прошедшие не включай.
- Опирайся только на найденное, ничего не выдумывай. Если по разделу мало настоящего — лучше меньше.
- Погоду и курсы валют не пиши — их добавит workflow.

## Формат текстов

- Язык — из `language`.
- Простой текст для Telegram, БЕЗ Markdown (никаких `*`, `#`, `**`). Заголовки разделов с эмодзи,
  пункты через «•», ссылки — просто URL на отдельной строке.
- Каждая новость: 1–2 предложения в кратком ироничном, юмористическом ключе + ссылка на источник.
  Шутим над подачей, а факты (что, где, когда, цифры) — точные.
- Если по разделу ничего стоящего не нашлось — так и напиши одной строкой.
- Без комментариев о поиске.
- `shared` — не длиннее ~3500 символов, чтобы подборка уместилась в одно-два сообщения Telegram.

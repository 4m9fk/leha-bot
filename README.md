# Telegram-бот: утренняя подборка по Витебску

Каждое утро бот присылает в Telegram кринжовую открытку «С добрым утром», карточку-инфографику (температура и дождь
по часам, курсы, главное сегодня) и подборку: приветствие по имени → 🔮 кринжовый гороскоп → 🎯 для тебя →
📰 новости Витебска → 🌍 мир коротко → 🌆 куда сходить вечером → 📅 план на выходные (по пятницам) →
☕ новое место недели (по понедельникам) → 🎭 афиша для взрослых → 🧸 для детей → 🎬 новинки кино → 💐 комплимент — и напоследок 😂 мем дня.
Названия в подборке — ссылки, длинные списки (мир, афиша, кино) свёрнуты под спойлер; открытки, мемы, новости
и советы не повторяются — routine ведёт архив прошлых выпусков. Сервер и Claude API не нужны.

**Как устроено.** В ~06:07 routine в Claude Code (облако, из твоей подписки) по инструкции `routine.md`
ищет новости, афишу, кино, открытку и мем дня и пишет каждому получателю личные приветствие, «для тебя» и комплимент.
Всё это она кладёт в `digest.json` в ветке `claude/shared`. В 08:00 GitHub Actions забирает файл, добавляет
погоду (Open-Meteo) и курсы (НБРБ), рисует карточку и рассылает. Если routine не отработала — придут
карточка, приветствие, погода и курсы.

**Знакомство.** При первом запуске бот спросит, как тебя зовут, и подождёт ответа 10 минут.
Поэтому первый раз запускай вручную (Run workflow) и держи Telegram под рукой.
Получатели, имена и интересы сохраняются в `state.json` в репозитории.

**Команды боту** (есть в меню «/» в Telegram). `/name Новое имя` — сменить имя; `/interests кино, концерты, спорт` — интересы для раздела
«Для тебя» (`/interests` без текста — сбросить); `/zodiac Лев` — знак для гороскопа (по умолчанию Дева). В 05:30 бот без звука обрабатывает входящие, и routine
учитывает их в тот же день. Telegram хранит сообщения для бота 24 часа.

**Несколько получателей.** Подписаться может любой, у кого есть ссылка-приглашение
`https://t.me/<имя_бота>?start=<INVITE_CODE>`: открыть её и нажать **Start**. Без ссылки бот посторонним
ничего не присылает. Личные тексты routine пишет только тем, кто был подписан к её запуску, — новенькие
в первый день получают общий вариант.

## Настройка (~15 минут)

### 1. Создай бота
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя.
2. Сохрани токен вида `123456789:AAH...`.

### 2. Придумай код приглашения
Любая строка из латиницы, цифр, `_` и `-` (до 64 символов), например:
```bash
python3 -c "import secrets; print(secrets.token_urlsafe(12))"
```
Это `INVITE_CODE`. Ссылка-приглашение: `https://t.me/<имя_бота>?start=<INVITE_CODE>` — открой её сам
и отправь тем, кому нужна подборка.

(Необязательно: вместо ссылки можно указать свой chat_id в `TELEGRAM_CHAT_ID` — его видно по адресу
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` в `"chat":{"id":...`, после того как напишешь боту.)

### 3. Залей код на GitHub
1. Создай **приватный** репозиторий, загрузи туда все файлы (включая папку `.github`).
2. Settings → Secrets and variables → Actions → **New repository secret**, добавь секреты:
   - `TELEGRAM_BOT_TOKEN`
   - `INVITE_CODE`
   - `TELEGRAM_CHAT_ID` (необязательно)

### 4. Создай routine в Claude Code
Нужна подписка Pro/Max/Team/Enterprise. На [claude.ai/code/routines](https://claude.ai/code/routines) → **New routine**
(или `/schedule` в Claude Code):
- **Репозиторий:** этот репозиторий (GitHub подключается через `/web-setup`).
- **Промпт:** `Выполни инструкции из routine.md.`
- **Модель:** самая мощная из доступных.
- **Расписание:** ежедневно в 06:07 по Минску (у запусков по расписанию бывает сдвиг до 30 минут).

Нажми **Run now** и проверь, что в репозитории появилась ветка `claude/shared` с файлом `digest.json`.

### 5. Проверь
Вкладка **Actions** → *Daily digest* → **Run workflow**. Через 1–3 минуты придёт сообщение.
Дальше — автоматически каждый день в 08:00 по Минску.

## Настройка под себя — `config.json`
| Поле | Что меняет |
|---|---|
| `sections` | общие разделы (их собирает routine веб-поиском, одни на всех получателей) по порядку — описывай словами, что хочешь в каждом; можно добавлять/удалять |
| `intro_sections`, `outro_sections` | личные разделы после приветствия и в конце (сейчас: гороскоп для Девы и комплимент) — routine пишет их под каждого получателя |
| `city` | город для новостей, афиши и заголовка карточки |
| `latitude`, `longitude` | координаты для погоды (сейчас Витебск) |
| `name_wait_minutes` | сколько ждать ответа на вопрос «Как тебя зовут?» |

Изменения в `config.json` и `routine.md` routine подхватит при следующем запуске.
Время рассылки — строки `cron` в `.github/workflows/digest.yml` (в UTC: Минск = UTC+3), время routine —
в её настройках.

## Локальный запуск
```bash
pip install -r requirements.txt
git fetch origin claude/shared && git show FETCH_HEAD:digest.json > digest.json   # тексты от routine
DRY_RUN=1 python digest.py   # напечатать подборку и сохранить card.png, ничего не отправлять
export TELEGRAM_BOT_TOKEN=... INVITE_CODE=...
python digest.py             # отправить в Telegram всем получателям
```

## Если что-то не так
- **Пришли только приветствие, погода и курсы** — routine не отработала: проверь её запуски на
  claude.ai/code/routines и что в ветке `claude/shared` лежит `digest.json` с сегодняшней датой в поле `date`.
- **`chat not found`** — ты не нажал Start у бота, или неверный chat_id.
- **Бот не отвечает на ссылку** — проверь, что код в ссылке совпадает с секретом `INVITE_CODE`;
  ответ придёт при ближайшем запуске workflow (05:30, 08:00 или ручном).
